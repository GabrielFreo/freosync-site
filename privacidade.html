Política de Privacidade

Última atualização: 8 de outubro de 2026

O FreoSync é um aplicativo de desktop para Linux que sincroniza arquivos entre o computador do usuário e o Google Drive do próprio usuário. Esta política explica quais dados ele acessa e o que faz com eles.

1. Dados acessados

Com a sua autorização (OAuth 2.0 do Google), o FreoSync acessa:

  • Arquivos e pastas do seu Google Drive (nomes, conteúdo, datas, tamanhos, pastas e itens compartilhados), por meio do escopo https://www.googleapis.com/auth/drive;
  • Informações básicas da conta: nome, endereço de e-mail e foto do perfil, para identificar a conta na interface do aplicativo.

2. Como os dados são usados

Os dados são usados somente para oferecer a função do aplicativo: listar seus arquivos, baixar para o seu computador os itens que você escolher sincronizar, enviar ao seu Drive as alterações feitas no computador e manter os dois lados iguais.

3. Armazenamento e compartilhamento

  • Tudo é processado localmente, no seu computador. O FreoSync não tem servidores e não envia seus dados a ninguém além do próprio Google.
  • O token de acesso fica guardado no chaveiro do sistema (gnome-keyring) do seu computador.
  • Uma cópia dos metadados (nomes, datas, identificadores) fica num banco local, em ~/.local/share/freosync, para que a sincronização funcione.
  • Nenhum dado é vendido, compartilhado com terceiros, usado para publicidade ou para treinar modelos de inteligência artificial.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google pelo FreoSync seguem a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso e apagar os dados

  • Remova a conta no FreoSync (Configurações da conta → Remover conta): o acesso é revogado e os dados locais do aplicativo são apagados.
  • Ou revogue a qualquer momento em myaccount.google.com/permissions.
  • Seus arquivos no Google Drive não são afetados pela remoção.
